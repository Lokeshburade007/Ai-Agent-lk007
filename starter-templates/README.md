# starter-templates

Boilerplates the local AI agent can clone from to bootstrap a new project quickly.

## Planned (Week 2 Task 4)

- `mern-starter/` — Express + Mongo + React
- `flutter-starter/` — Clean architecture + Riverpod + MVVM
- `swiftui-mvvm-starter/`
- `go-backend-starter/`
- `auth-boilerplate/`
- `api-template/`
- `docker-template/`

## How the agent uses these

Aider / Continue.dev can be pointed at one of these directories as a "copy and adapt" base instead of generating everything from scratch every time. Generation is slow on 7B local; copying is instant.
