# ai-workflows

Documentation for the agentic coding workflows that turn the local Ollama model into a Claude-Code-like system.

## Planned content

- Continue.dev configuration recipes (`config.json` patterns)
- Aider invocation patterns per task type
- Pre/while/post-coding workflow prompts (Week 3 Task 5)
- Git-aware development conventions (commit cadence, branch naming the agent respects)
- Personal AI Engineering Handbook (Week 4 Task 4): coding standards, architecture patterns, debugging workflows, deployment steps, prompt patterns

## Why a separate repo

Workflows reference *prompts* and *templates* but live independently so they can be cloned into any new project without dragging in the whole library.
